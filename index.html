Kebijakan Privasi VocaFlip

Berlaku sejak 29 Oktober 2026 · Aplikasi Android VocaFlip (com.capseran.vocaflip)

VocaFlip ("aplikasi") adalah aplikasi flashcard untuk belajar kosakata bahasa Inggris yang dikembangkan oleh Capseran ("kami"). Kebijakan ini menjelaskan data apa yang diproses aplikasi dan ke mana data itu dikirim.

Ringkasan

  • Kami tidak memiliki server dan tidak mengumpulkan data pribadi, akun, lokasi, kontak, atau ID perangkat.
  • Deck, kartu, jadwal review, streak, dan pengaturan hanya tersimpan di perangkatmu.
  • Aplikasi tidak memuat iklan maupun alat analitik atau pelacakan.

Data yang tersimpan di perangkat

  • Deck dan kartu kosakata, termasuk yang kamu buat sendiri
  • Progres belajar: jadwal spaced repetition, jumlah review harian, streak, dan skor Quick Match
  • Pengaturan aplikasi
  • API key Claude, jika kamu memasukkannya, disimpan terenkripsi dengan Android Keystore

Data ini dapat ikut dicadangkan oleh fitur Backup Android milik Google sesuai pengaturan akunmu, kecuali API key Claude yang sengaja dikecualikan dari backup.

Data yang dikirim ke layanan pihak ketiga

1. Free Dictionary API (dictionaryapi.dev). Saat kamu memutar pelafalan atau memakai "Isi otomatis" tanpa AI, kata bahasa Inggris yang bersangkutan dikirim ke dictionaryapi.dev untuk mengambil rekaman audio dan definisi. Hanya kata tersebut yang dikirim, tanpa informasi tentang dirimu.

2. Anthropic (Claude API), hanya jika kamu mengaktifkan fitur AI. Fitur AI bersifat opsional dan memakai API key milikmu sendiri. Saat kamu menekan "Buat Kalimat" atau "Isi otomatis" dengan AI aktif, kata, jenis kata, arti, dan definisi dari kartu tersebut dikirim ke Anthropic untuk menghasilkan contoh kalimat. Permintaan ini terikat pada akun Anthropic pemilik API key dan diproses sesuai kebijakan privasi Anthropic.

3. Mesin text-to-speech perangkat. Jika rekaman tidak tersedia, teks diucapkan oleh mesin text-to-speech di perangkatmu (misalnya Google Speech Services), sesuai kebijakan penyedia mesin tersebut.

Semua koneksi menggunakan HTTPS.

Izin aplikasi

VocaFlip hanya meminta izin Internet, yang dipakai untuk audio pelafalan, kamus, dan fitur AI opsional. Aplikasi tidak mengakses kamera, mikrofon, lokasi, kontak, maupun file pribadimu.

Mengelola dan menghapus data

  • Hapus API key kapan saja di Progres → Pengaturan → AI Context Generator → Hapus.
  • Reset progres belajar di Pengaturan → Data → Reset progres belajar.
  • Hapus semua data dengan menghapus data aplikasi di pengaturan Android, atau dengan meng-uninstall aplikasi.

Karena kami tidak menyimpan data di server, tidak ada data di pihak kami yang perlu dihapus.

Anak-anak

Aplikasi ini ditujukan untuk pengguna berusia 13 tahun ke atas dan tidak dengan sengaja mengumpulkan data dari anak-anak.

Perubahan kebijakan

Jika kebijakan ini berubah, versi terbaru akan dipublikasikan di halaman ini dengan tanggal berlaku yang diperbarui.

Kontak

VocaFlip Privacy Policy

Effective October 29, 2026 · VocaFlip for Android (com.capseran.vocaflip)

VocaFlip ("the app") is a flashcard app for learning English vocabulary, developed by Capseran ("we"). This policy explains what data the app handles and where it is sent.

Summary

  • We have no servers and collect no personal data, accounts, location, contacts or device identifiers.
  • Your decks, cards, review schedule, streak and settings are stored only on your device.
  • The app contains no ads and no analytics or tracking tools.

Data stored on your device

  • Vocabulary decks and cards, including ones you create
  • Study progress: spaced-repetition schedule, daily review counts, streak and Quick Match scores
  • App settings
  • Your Claude API key, if you enter one, encrypted with the Android Keystore

This data may be included in Google's Android Backup according to your account settings, except the Claude API key, which is deliberately excluded from backups.

Data sent to third-party services

1. Free Dictionary API (dictionaryapi.dev). When you play a pronunciation or use "Auto-fill" without AI, the English word is sent to dictionaryapi.dev to fetch audio and a definition. Only that word is sent, with no information about you.

2. Anthropic (Claude API), only if you enable the AI feature. The AI feature is optional and uses your own API key. When you tap "Generate sentences" or "Auto-fill" with AI enabled, the card's word, part of speech, meaning and definition are sent to Anthropic to generate example sentences. These requests belong to the Anthropic account that owns the API key and are handled under Anthropic's privacy policy.

3. On-device text-to-speech. When no recording is available, text is spoken by your device's text-to-speech engine (for example Google Speech Services), under that provider's policy.

All connections use HTTPS.

Permissions

VocaFlip only requests the Internet permission, used for pronunciation audio, the dictionary and the optional AI feature. The app does not access your camera, microphone, location, contacts or personal files.

Managing and deleting data

  • Remove your API key at any time in Progres → Pengaturan → AI Context Generator → Hapus.
  • Reset study progress in Pengaturan → Data → Reset progres belajar.
  • Delete all data by clearing the app's storage in Android settings or by uninstalling the app.

Because we store nothing on servers, there is no data on our side to delete.

Children

The app is intended for users aged 13 and over and does not knowingly collect data from children.

Changes to this policy

If this policy changes, the new version will be published on this page with an updated effective date.
